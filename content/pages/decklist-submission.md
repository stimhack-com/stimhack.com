The WordPress submission form is gone. Tournament results now live in a data
file in the site's repository, so you can add one through a GitHub pull request:

1. Open {{< repo "edit/main/data/decklists.yaml" >}}data/decklists.yaml{{< /repo >}}
   on GitHub.
2. Add an entry at the top of the list, in the same format as the others.
3. Propose the change. A maintainer reviews and merges it.

If you prefer not to use GitHub, {{< repo "issues/new" >}}open an issue{{< /repo >}}
with the tournament details, or contact us at stimhack(at)gmail(dot)com.
