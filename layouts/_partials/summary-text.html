{{- /* Summary of a page as plain text. Migrated posts have the WordPress excerpt as plain text in front matter summary. Hugo renders that as Markdown in .Summary, and a summary divider in the content replaces it, so use it as written. New posts use the summary Hugo makes from their content. For content that is only an iframe or an image, Hugo makes a summary that is only white space. Trim it, so that the summary of such a post is empty and baseof.html uses the site description. */ -}} {{- $text := "" -}} {{- with .Params.summary }}{{ $text = . }}{{ else }}{{ $text = .Summary | plainify | htmlUnescape }}{{ end -}} {{- return strings.TrimSpace $text -}}
